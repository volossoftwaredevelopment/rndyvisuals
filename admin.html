GitHub access

Create one at github.com/settings/personal-access-tokens → “Fine-grained tokens” → Generate new token. Repository access: only . Permissions: Contents — Read and write and Actions — Read-only. The token is stored in this browser only.

Videos — top to bottom is the order on the site

    Upload a web-encoded MP4 (H.264) under 60 MB — a poster frame is generated automatically. Or use “Replace video” on a row to swap an existing film.
